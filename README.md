# Teachers' Day Interactive Message Card

A creative, professional, and customizable Teachers' Day greeting card built with **HTML, CSS, and JavaScript**.

## Features

- 🔄 3D flip-card animation
- ✍️ Custom teacher name
- 💌 Custom personal message
- 🖊️ Custom sender/student name
- 🖼️ Add your own photo directly in the card
- 🎵 Add a personal audio message
- 🎨 Customize the card and accent colors
- 💾 Save text/color settings in the browser using Local Storage
- 📱 Responsive design for desktop, tablet, and mobile
- 🔒 Photos and audio are processed locally in the browser and are not uploaded by the webpage
- ♿ Keyboard support for opening/flipping the card

## How to Use

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter the teacher's name.
4. Enter your own name.
5. Write a personalized Teachers' Day message.
6. Click **Add Photo** to select a photo from your computer.
7. Click **Add Audio** to select a voice recording or music/audio file.
8. Choose your preferred card and accent colors.
9. Click **Save Card Settings** if you want the text/color settings remembered on that browser.
10. Click the card to flip it and view the completed greeting.

### Important

The selected photo and audio are loaded locally in the browser. They are not automatically uploaded to GitHub or any server.

If you want the faculty member to receive the same photo/audio when they open the GitHub Pages link, you should add those media files to the repository and reference them in the HTML/JavaScript. The current version intentionally lets the sender choose files from their own device.

## GitHub Upload Instructions

### 1. Create a repository

1. Sign in to GitHub.
2. Click **New repository**.
3. Name it something like:

```text
teachers-day-message-card
```

4. Set the repository to **Public**.
5. Create the repository.

### 2. Upload the project

Upload these files:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

### 3. Enable GitHub Pages

After uploading:

1. Open the repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to publish the website.
8. GitHub will provide a public website URL.

Your submission can then include both the repository link and the GitHub Pages link.
